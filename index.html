Sobre mí

Soy un desarrollador frontend junior con foco en crear webs reales para negocios locales. No hago demos genéricas — cada proyecto ha sido pensado para un negocio concreto, con sus necesidades y su identidad.

Trabajo principalmente con HTML, CSS y React para webs a medida, y con Shopify y WordPress cuando el cliente necesita gestionar su propio contenido o tienda.

Tengo un nivel medio en SEO: optimización on-page, estructura de headings, metadatos, schema markup y mejora de Core Web Vitals para que los proyectos no solo se vean bien, sino que también posicionen.

Una de mis ventajas diferenciales es el dominio de herramientas de IA como Claude para acelerar el desarrollo, integrar funcionalidades inteligentes y entregar proyectos de mayor calidad en menos tiempo.

Busco mi primera oportunidad estable donde seguir creciendo y aportar valor desde el primer día.
